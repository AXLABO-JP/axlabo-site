How we work — Source → Transform → Publish

今ある情報から、つくる。

新しい入力フォームを一から埋めていただく必要はありません。お手持ちのURL・PDF・CSV・SNS・資料をお送りいただければ、AXLABOが整理します。足りない情報だけ、あとから確認します。

3つの段階

  1. SOURCE

    今ある情報をお預かりする

    新しいフォームを一から埋めていただく必要はありません。URL・PDF・CSV・SNS・既存資料をそのままお送りください。

    • URL
    • PDF
    • CSV
    • SNS
    • 既存資料
  2. TRANSFORM

    AIで整理・変換する

    事実情報を抜き出して整理し、読み手と用途に合わせて再構成します。足りない情報だけ、あとからお尋ねします。

    • 抽出
    • 整理
    • 翻訳
    • 再構成
  3. PUBLISH

    確認いただいてから公開する

    プレビューをご確認いただき、ご承認後に公開・納品します。無断で公開・送信することはありません。

    • プレビュー
    • ご承認
    • 公開・納品

実際の工程と、担当

お客様にお願いするのは、最初のお預かりと、公開前のご確認の2か所です。

  1. SOURCEお預かり

    お預かりお客様

    WebサイトのURL、PDF、CSV、SNSアカウント、既存の原稿など、今ある情報をそのままお送りください。

  2. IMPORT / NORMALIZE取り込み・整理

    取り込み・整理AI

    事実情報を抜き出し、AXLABOの標準の形式に整理します。どの情報をどこから得たか(出所)も記録します。

  3. TRANSFORM変換・再構成

    変換・再構成AI

    日本語化・多言語化や、読み手と用途に合わせた構成への組み替えを行います。元の文章をそのまま写すことはしません。

  4. GENERATE制作

    制作AI

    Webページ・掲載ページ・レポート・音声・動画など、目的の形式に仕上げます。

  5. REVIEW点検

    点検AI + 代表者

    誤り・不足・権利の確認が必要な素材がないかを点検します。足りない情報だけ、お客様にお尋ねします。

  6. PREVIEW / APPROVALご確認・ご承認

    ご確認・ご承認お客様

    公開前のプレビューをご確認いただきます。修正のご希望もここで伺います。

  7. PUBLISH公開・納品

    公開・納品AXLABO

    ご承認をいただいてから、公開・納品します。

お送りいただけるもの

受け取れる形式は、事業によって異なります。迷ったら、まずはあるものをそのままお送りください。

  • WebサイトのURL店舗・会社のサイト、Googleの店舗情報、既存のLP
  • PDF・資料会社案内、メニュー、物件資料、商品資料、営業資料
  • CSV物件・商品などの一覧。Excelの場合は、CSV(UTF-8)での書き出しをお願いすることがあります
  • SNSアカウント公開されている投稿・プロフィール
  • 原稿・メモ既存の文章、会議の文字起こし・メモ(AI議事録は現在、音声ファイルからの作成に対応していません)

コピーではなく、再構成

元のページは「入力源」として使います。そのまま複製して公開することはしません。

  • 事実情報を抜き出し、文章はAIで書き起こし直します
  • 情報の出所(Source URL)を記録し、確認済みの情報と推測を区別します
  • 権利を確認できていない画像・文章・レビューは転載しません
  • 足りない情報を、事実のように補って書くことはしません
  • お客様にご確認いただいてから公開します

まずは、今ある資料を送ってください。

サイトのURLや資料をお送りいただければ、何ができそうか・何が足りないかを整理してご返信します。ご相談・お見積りは無料です。
